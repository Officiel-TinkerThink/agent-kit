# Fixed-rate interest accrual: intent and requirements

Intent: the loan ledger computes simple interest on a principal at a fixed annual rate, on an actual/365 day basis, for any start and end date. accrue_interest returns the interest accrued from start up to the end date, rounded to cents with banker's rounding. The end date is the explicit as_of argument when given; when it is not given, the end date is taken from the injected clock, and when no clock is injected, from the current UTC date. A negative principal, a negative rate, or an end date before the start date is rejected with ValueError. The function is pure apart from reading the time, so that the same inputs always produce the same interest for the same end date. Requirements: the function must not be called with a floating-point principal or rate, and the result must be a Decimal quantized to 0.01.
